# F004 — No example review records a RaC version

Status: open

Severity: informational

Location:
examples/*/review.md

## Observation

SPEC Section 15.1 defines the `rac_version` projection as derived from a `RaC version: v0.4.0` line, and Section 6 recommends recording the protocol version "for forward compatibility". None of the example review files (`examples/R017/review.md`, `examples/R042/review.md`, `examples/R055/review.md`) include a `RaC version:` line, so the `rac_version` projection is exercised nowhere and the recommended forward-compat metadata is absent from every reference example.

## Recommendation

Add a `RaC version: v0.4.0` line to each example `review.md`, which would both exercise the `rac_version` projection and document the recommended metadata in the reference artifacts.
