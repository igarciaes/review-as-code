# F002 — Severity vocabulary is not defined in SPEC

Status: open

Severity: low

Location:
SPEC.md, Section 7

## Observation

The finding severity vocabulary (`critical | high | medium | low | informational`) is defined only in `schemas/finding.schema.json` and `.review/README.md`. `SPEC.md` references severity as part of a finding (`severity when applicable`, Section 7) and in the reviewer ownership list (Section 9.1), but never normatively states the allowed values. A repository following only `SPEC.md` has no canonical severity values.

## Recommendation

Document the recommended severity vocabulary in SPEC Section 8 (alongside Decision and Verification), mirroring how those vocabularies are defined with "Recommended values".
