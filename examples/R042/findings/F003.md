# F003 — Idempotency keys not required

Status: closed

Severity: medium

Location:
src/payment/client.ts

## Observation

Payment requests do not require idempotency keys, which risks duplicate charges on retry.

## Recommendation

Require an idempotency key on every payment request.

## Decision

Status: accepted_risk

Rationale:
The integration layer guarantees single delivery; the risk is accepted for the current release.
